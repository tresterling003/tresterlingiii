# tresterlingiii

| Folder | What it is |
|---|---|
| [`audiobooks/`](audiobooks/) | **Earshot** (live at https://tresterlingiii.vercel.app/earshot). Free LibriVox audiobook player: search and browse ~18,900 recordings, resume where you left off, speed, sleep timer, bookmarks, lock-screen controls; installs on a phone (Vite + React, static, no server). See its README. |
| [`voice-quest/`](voice-quest/) | **Voice Quest: Christmas Kingdom.** Voice-interactive 3D adventure for young children practicing communication (TypeScript + Three.js + Vite). See its README. |
| [`character-creator/`](character-creator/) | **Cartoon Character Creator.** Quiz-style character discovery tool for Digital Arts & Animation students: character brief, story idea, and a ready-to-copy 5-sketch AI prompt (React + Vite). See its README. |
| [`rival/`](rival/) | **Christmas HQ** (live at https://tresterlingiii.vercel.app). Family Christmas dashboard: wishlists with sizes, photos and links, secret gift claims, gift tracker, budget, gift finder, games with a family leaderboard, and free themes and avatars in Settings (Next.js + Postgres). The folder is named `rival/` because that is the folder the existing Vercel project builds. See its README. |
| [`rival-fitness/`](rival-fitness/) | **RIVAL — Fantasy Fitness** (retired; replaced on Vercel by Christmas HQ). Next.js + Postgres. Its tables are still in the database, untouched. |
| [`christmas-list/`](christmas-list/) | **Christmas List.** Shareable wish list for family: exact picks with size, colour, photo and shop links, plus open gift ideas and an "about me" card. Single HTML file, hosted as a claude.ai artifact. |
| [`christmas/`](christmas/) | Christmas Broadside trivia game (single HTML file). |
| [`review/`](review/) | Economics review game (single HTML file). |
