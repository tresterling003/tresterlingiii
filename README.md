# tresterlingiii

| Folder | What it is |
|---|---|
| [`rival/`](rival/) | **RIVAL — Fantasy Fitness.** Head-to-head fitness leagues for friends and family (Next.js + Postgres). See its README. |
| [`voice-quest/`](voice-quest/) | **Voice Quest: Christmas Kingdom.** Voice-interactive 3D adventure for young children practicing communication (TypeScript + Three.js + Vite). See its README. |
| [`character-creator/`](character-creator/) | **Cartoon Character Creator.** Quiz-style character discovery tool for Digital Arts & Animation students: character brief, story idea, and a ready-to-copy 5-sketch AI prompt (React + Vite). See its README. |
| [`endzone/`](endzone/) | **END ZONE! QB Showdown.** First-person 3D American football game (Three.js): fixed ultra-wide view from the QB's spot; pick a play, snap, swipe toward a receiver to throw (swipe length = distance, flick speed = bullet vs lob), then steer and juke after the catch. 12 career drives, Field Goal Frenzy, team locker room. Single HTML file. |
| [`golazo/`](golazo/) | **GOLAZO! Draw. Curve. Score.** Swipe-to-shoot soccer game: draw your shot to bend it, pass to team-mates, bicycle kicks, 15 career levels, 3 minigames (Target Smash, Penalty Pressure, Foot Golf) and a locker room to customise your player (single HTML file, plays on phones). |
| [`christmas/`](christmas/) | Christmas Broadside trivia game (single HTML file). |
| [`review/`](review/) | Economics review game (single HTML file). |
